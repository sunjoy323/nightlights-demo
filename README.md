# 夜灯将眠

环球电工阿灯上夜班，把灯关了，好让城市看见星空。一页自包含 H5 demo（无 CDN）。

线上：https://sunjoy323.github.io/nightlights-demo/

- 小电工走过 25 座真实城市、500 关。每章一座城、20 关；关名是当地街区。章末关掉地标，才能看见这座城自己的天空。图鉴按城市收集明信片和邮戳。
- 玩法对齐「蚂蚁搬画」：夜景先出现，点最前排工单，电工去关露在外面的同色灯，电闸 5 槽。卡住时可以时光倒流，或看一段演示广告加一个槽。
- 教学只占前 5 关（解法与原来相同）。之后维持中高难度：贪心过不去，随机乱点胜率低于 10%。每 10 关一座大关（第 20、40… 是章末大关），按「关键决策序列」唯一，且不用倒流/广告。
- 够不着的工单不会在托盘上写「等」，进槽之后才会 zz。机关图标、锁和钥匙的连线还在。
- 500 关全部预生成并打进包（`levels-bank.js`）。生成器还在，以后可以继续往后面扩。
- 测试用：在选关页连点标题「夜灯将眠」5 次，可全部解锁。

本地预览：

```
python3 -m http.server 8080 --directory .
```

打包：`python3 pack.py`（core / world / landmarks / gen / levels-bank / game / css 打进 `index.html`）。
验关：`node verify.mjs`（默认 500 关；前 5 关解法路径保持不变）。
曲线：`python3 docs/plot_curve_500.py` → `docs/curve-1-500.png`。
