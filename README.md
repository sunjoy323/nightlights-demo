# 夜灯将眠

把通明的城市，一盏盏关掉。一页自包含 H5 demo（无 CDN）。

- 玩法结构对齐「蚂蚁搬画」：完整夜景先出现，点最前排工单，电工自动关露在外面的同色灯，电闸 5 槽。卡住时可以时光倒流，或看一段演示广告加一个槽。
- 前 20 关手调（主题、机关、解法保留），第 21 关起由种子化生成器无限供给，选关页按章翻页，最多列出 1000 关。
- 每种机关有统一标记：锁和钥匙同色同图标，并用虚线连上；被锁的格子有暗纹和「锁」字；够不着的颜色在托盘上提前标「等」，不必等进槽才 zz。点住工单可以预览「进槽后电工能不能干活」。新机关第一次出现会弹出一张短图示卡。
- 通关后关掉的城市收进「夜景图鉴」，带星级、关卡名和一句旁白，可以回看。每 10 关是一张地标明信片。
- 难度按锯齿走：每 5 关一个小坑，每 10 关一个难关，随后 1–2 个放松关；新机关那关只教一件事。生成后必须过求解器。1–1000 关曲线见 `docs/curve-1-1000.png`。
- 测试用：在选关页连点标题「夜灯将眠」5 次，可全部解锁。

本地预览：

```
python3 -m http.server 8080 --directory .
```

打包：`python3 pack.py`（把 `core.js` / `gen.js` / `game.js` / `style.css` 打进 `index.html`）。
验关：`node verify.mjs`（默认前 30 关，前 5 关解法路径保持不变）。
曲线：`node curve.mjs 1000`，再 `python3 docs/plot_curve.py`。
